СБОРКА ЧЕРЕЗ GITHUB ACTIONS
(ничего не ставить на свой компьютер — JDK и Gradle не нужны)

1. Создайте новый репозиторий на github.com (любое имя, публичный
   или приватный — не важно).
2. "Add file" -> "Upload files" -> перетащите туда ВСЕ файлы и папки
   из этого архива, включая папку .github, и нажмите Commit changes.
3. Откройте вкладку Actions — сборка запустится сама автоматически.
   Занимает пару минут, в конце появится зелёная галочка.
4. Кликните на завершившийся запуск -> Artifacts -> quartzclimb-jar
   -> скачать. Внутри архива будет quartzclimb-0.1.0.jar — это и есть
   рабочий мод. Файл quartzclimb-0.1.0-sources.jar рядом — это просто
   исходники, он не нужен, в mods его класть не надо.

Если Actions покажет красный крестик вместо зелёного — откройте лог
запуска и пришлите мне текст ошибки, здесь она точно не потеряется.
